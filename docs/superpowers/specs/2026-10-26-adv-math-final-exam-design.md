# Advanced Math Studio 중간/기말 분리 설계

작성일: 2026-10-26 · 대상 페이지: `adv_math.php`

## 1. 왜 하는가

Advanced Math Studio에 있는 문제(역삼각함수·쌍곡함수·극좌표·정적분의 활용·고급대수·증명)는 모두 **중간고사 범위**다. 이제 **기말고사**를 준비해야 하고, 범위는 교과서(`참고자료/미적분/고급미적분 교과서.pdf`)의

- **III. 급수** (p.98–155): 급수의 수렴과 발산, 멱급수
- **IV. 미분방정식** (p.156–191): 미분방정식, 미분방정식의 활용

이다. 실제 시험에서 **미분방정식은 2문제 정도이고 대부분이 급수**다. 연습 문제 분량도 이 비율을 따른다.

## 2. 목표 · 비목표 · 실패 조건

**목표**
- 문제집 창의 최상위를 `중간고사 | 기말고사`로 나누고, 각각의 안에 과목 탭을 둔다.
  - 중간고사: 역삼각함수 · 쌍곡함수 · 극좌표 · 정적분의 활용 · 고급대수 · 증명 (기존 그대로)
  - 기말고사: 급수 · 미분방정식 · 실전 모의
- 기말 문제는 급수 판정(절대수렴/조건수렴/발산), 수렴구간, ∞ 같은 답을 받을 수 있게 채점을 유연하게 한다.
- 기말 문제의 모든 정답을 SymPy로 독립 검증한다.

**비목표**
- 중간고사 문제·채점·화면을 바꾸는 것
- DB 스키마 변경, 별도 페이지 신설, 중간/기말 리더보드 분리
- 서술형(증명) 채점
- 기말 증명 탭 (사용자 결정: 넣지 않음)

**실패 조건 (동작해도 이러면 실패)**
- 중간고사 문제 중 하나라도 채점 결과가 예전과 달라진다.
- 판정 문제에서 "포기"나 엉뚱한 판정이 정답 처리된다.
- 기말 화면이 중간과 다른 디자인처럼 보인다(색·카드·버튼 모양이 달라짐).
- 교과서 예제·문제를 그대로 옮겨 적는다. (유형과 개념은 교과서를 따르되 수치와 구성은 새로 만든다.)

## 3. 현재 구조 (구현에 필요한 사실)

- 문제집 창: `adv_math.php:390` `.subject-tabs` 아래 6개 탭, `switchModalSubject()`(`:778`)가 `MODAL_SUBJECTS` 배열로 탭·섹션을 토글한다.
- 미적분 문제집은 `window.generatedCollections` 하나에 모이고, id 부분 문자열로 탭이 정해진다(`:906`). 분류 안 된 id는 전부 극좌표 탭으로 간다.
- 시작: `startSelectedGame()`(`:1019`)이 `selectedSubject`('calc' | 'algebra')로 분기한다. 대수는 페이지 안의 `startAlgebraGame()`을 쓴다.
- 채점: `logic.js`의 `finishTest()`가 문제마다 전역 `gradeProblem(user, sol, strictC, timeout, exact)`(`grader.js:451`)를 호출하고, 이것이 Pyodide 워커의 SymPy `grade()`를 실행한다. `gradeProblem`은 전역 함수 선언이라 페이지 스크립트에서 감쌀 수 있다(`renderMath`, `giveUpProblem`도 같은 방식으로 이미 덮어쓰고 있다).
- 채점기 한계: 수치 비교는 변수 `x`에만 값을 넣는다. 답의 `C`는 0으로 바뀐다. `\infty`, 구간, 판정 문장은 처리하지 못한다. `발산` 센티널은 "포기"도 정답으로 받는다.
- 점수: `study_scores.js` → `api/study_scores.php`. studio는 `advanced_math`, `collection_id`는 `^[A-Za-z0-9_-]+$`·100자 이하면 된다. DB 변경이 필요 없다.
- `grader.js`, `logic.js`는 `integral.php`도 같이 쓴다.

## 4. 고려한 방식

| 방식 | 내용 | 판단 |
|---|---|---|
| **A. 한 페이지, 문제집 창 최상위에 중간/기말** | 문제집 창에 시험 탭 줄을 추가하고, 그 아래 과목 탭을 시험별로 바꿔 보여준다. 기말 기능은 새 스크립트 `scripts/adv_final.js`에 둔다. | **채택.** 사용자가 원한 "중간 누르면 그 안에 역삼각함수, 쌍곡함수…" 구조 그대로다. 화면·스타일·점수 저장을 공유해서 디자인이 자동으로 같다. |
| B. 기말 전용 페이지 | `adv_math.php`를 복사해 기말 페이지를 만든다. | 1,000줄 페이지가 두 벌이 되어 한쪽만 고치면 디자인이 갈라진다. |
| C. 기존 채점기(`grader.js`)에 판정·구간을 직접 추가 | Python 채점 코드를 수정한다. | `integral.php`와 중간고사까지 영향을 받는다. 기말 세션에서만 동작하는 JS 래퍼로 충분하다. |

## 5. 화면 설계

### 5.1 문제집 창

```
┌ 문제집 목록 ─────────────────────────────── ✕ ┐
│  [ 중간고사 ] [ 기말고사 ]          ← 시험 탭  │
│  [급수] [미분방정식] [실전 모의]     ← 과목 탭  │
│  ▶ 급수 · 교과서 III단원 (p.98–155)           │
│  ┌카드┐ ┌카드┐ ┌카드┐ ...                     │
└───────────────────────────────────────────────┘
```

- 시험 탭은 과목 탭 위에 한 줄. 기존 `.subject-tab` 색·모서리를 그대로 쓰고 글자만 조금 크고 굵게 한다. 모바일에서는 두 버튼이 반반 폭.
- 시험 탭을 누르면 그 시험의 과목 탭만 보이고, 그 시험에서 마지막으로 보던 과목 탭이 열린다.
- 처음 들어오면(저장된 선택 없음) **기말고사 → 급수** 탭이 열린다.
- 카드는 기존 `buildCollectionCard()`를 그대로 쓴다(설명이 있는 카드 형태).

### 5.2 시작 카드

- 선택한 문제집 이름 앞에 `중간 · ` / `기말 · `을 붙인다.
- 이용 가이드와 옵션은 **선택한 문제집의 시험**을 따른다.
  - 중간: 지금 가이드와 옵션(적분상수 C, 증명 해설 펼치기) 그대로
  - 기말: "판정 문제는 아래 판정 버튼으로 답하세요", "수렴구간은 구간 버튼으로 `[a,b)` 꼴로 입력하세요", "미분방정식의 해는 `y=` 없이 우변만 입력하세요", "값은 소수 대신 정확한 값(분수·근호·π·e)으로 입력하세요". 옵션 두 개는 숨긴다.
- 마지막 선택(시험+문제집)은 `localStorage`(`adv_last_exam`, `adv_final_selected`)에 저장한다. 읽기·쓰기는 try/catch로 감싸고, 실패하면 기본값을 쓴다. 중간 문제집은 지금처럼 `selected_collection` 쿠키를 그대로 쓴다.

### 5.3 문제 풀이 화면 (기말)

- 헤더·입력칸·버튼 배치는 중간과 같다. 슬로건만 `Converge with confidence`(급수/모의) · `Solve the flow`(미분방정식).
- 입력칸 아래 도구 줄(행렬 버튼 자리, 같은 `btn secondary` 스타일)은 문제의 `tools` 필드에 따라 바뀐다. 정답이 아니라 **문제 유형**으로 정하므로 버튼이 답을 흘리지 않는다.
  - `verdict`: `절대수렴` `조건수렴` `수렴` `발산` 버튼. 누르면 입력칸을 `\text{절대수렴}` 등으로 **바꾼다**(덧붙이지 않음).
  - `interval`: `[a,b]` `[a,b)` `(a,b]` `(a,b)` 템플릿과 `∞` 버튼
  - `value`(기본값): `∞` `발산` 버튼 — 값 문제 전체에 똑같이 보여서 답이 ∞인지 발산인지 드러나지 않는다.
  - `expr`: 도구 없음 (테일러 다항식, 미분방정식의 해)
- **포기 버튼은 기말에서 숨긴다.** 기말에는 "적분 불가능" 유형이 없다.

### 5.4 결과 화면

- 기존 `renderResult` 형식을 그대로 쓰되, 정답 표시는 형식 접두어를 떼고 보여준다(`verdict:조건수렴` → `\text{조건수렴}`).
- 해설 요약 줄에 교과서 쪽을 붙인다: `풀이 해설 · 비판정법 · 교과서 p.118`.
- 기말 문제에는 `+ C`를 붙이지 않는다.

### 6.2 형식

```js
{
  id: 'fin_ser_05_v1', unit: 'series',           // 'series' | 'ode' | 'mock'
  name: '급수 5 · 비판정법과 근판정법',
  description: '이웃 항의 비, n제곱근의 극한 · 교과서 p.118–123',
  problems: [{
    id: 'fin_ser_05_v1_ratio_factorial', template: 'fin_ser_05_v1_ratio_factorial',
    level: 3, title: '계승이 섞인 일반항의 비',
    latex: String.raw`\text{급수 }\sum_{n=1}^{\infty}\frac{n!}{n^n}\text{의 수렴, 발산을 판정하시오.}`,
    solution: 'verdict:수렴',
    explanation: String.raw`...`,
    answerMode: 'exact', page: 118, tools: 'verdict'
  }]
}
```

- `tools`: `'verdict' | 'interval' | 'value' | 'expr'`. `verdict:발산` 정답은 `tools`가 `verdict`나 `value`일 수 있다("수렴하면 합을, 발산하면 발산이라 답하시오" 유형).

- 문장은 기존 파일처럼 `\text{}` 안에 한국어, 밖에 수식. 작성은 `lesson_calculus_collections.js`의 `tex()` 헬퍼(`$...$` → `\text{}` 변환) 방식을 쓴다.
- **정답 형식 (`solution`)**
  - 식·값: 그냥 LaTeX. 예 `\frac{1}{6}`, `1-\frac{x^2}{2}+\frac{x^4}{24}`, `2e^{-x}+x-1`
  - 판정: `verdict:절대수렴` | `verdict:조건수렴` | `verdict:수렴` | `verdict:발산`
  - 구간: `interval:[-1,1)`, `interval:(-\infty,\infty)`
  - 무한대: `\infty`
- 함수 답은 독립변수를 `x`로 쓴다(채점기의 수치 비교가 `x`만 지원). 시간 `t`가 자연스러운 활용 문제는 특정 시점의 값이나 걸리는 시간처럼 숫자를 묻는다.
- 미분방정식은 초깃값 문제만 낸다(일반해의 `C`는 채점 불가).
- id 규칙: 문제집 `fin_{ser|ode|mock}_{두자리}_v1`, 문항 `{문제집id}_{영문키}`. 기존 id와 겹치지 않는다.

## 7. 채점 설계 (`scripts/adv_final.js`)

기말 세션(`state.exam === 'final'`)일 때만 전역 `gradeProblem`을 감싼다. 중간 세션에서는 원래 함수를 그대로 호출하므로 중간 채점은 바뀌지 않는다.

1. **판정 (`verdict:`)**: 입력에서 `\text{}`·공백·`\,`를 지우고 비교한다.
   - `수렴` 정답 → `수렴`, `절대수렴` 모두 정답 (양항급수가 수렴하면 절대수렴이므로)
   - `절대수렴`, `조건수렴`, `발산` 정답 → 정확히 같은 말만 정답
   - "포기"·빈칸·다른 말 → 오답. 원래 채점기로 넘기지 않는다.
2. **구간 (`interval:`)**: `\left`, `\right`, `\lbrack`, `\rbrack` 등을 정규화하고 `[`/`(`, 쉼표, `]`/`)`로 나눈다.
   - 괄호 종류가 양쪽 모두 같아야 한다.
   - 끝점이 `\infty` / `-\infty`면 문자 비교, 아니면 원래 `gradeProblem(u, s, false, timeout, true)`로 숫자 비교
   - 구간 꼴이 아니면 오답
3. **무한대 (`\infty`)**: `\infty`, `+\infty`, `∞`를 정답으로. 그 외 오답
4. **그 밖의 식·값**: 원래 `gradeProblem(u, s, false, timeout, true)` — 기말은 적분상수를 요구하지 않는다.

반환값은 원래 함수와 같은 문자열(`"CORRECT"`, `"INCORRECT"`, `"EMPTY INPUT"`)이라 `finishTest()`는 고치지 않는다.

**세션 구분과 로드 순서**
- `startFinalGame()`이 `state.exam = 'final'`, `state.subject = 'final'`로 둔다. `startSelectedGame()`은 중간 문제집으로 시작할 때 먼저 `state.exam = 'midterm'`으로 둔다(`logic.js`의 `startGame()`은 고치지 않음).
- `logic.js`는 `DOMContentLoaded`에서 쿠키의 중간 문제집을 자동 선택한다(`logic.js:132`). `adv_final.js`는 `logic.js` 뒤에 로드되어 자기 `DOMContentLoaded`에서 `adv_last_exam === 'final'`이면 기말 선택을 복원해 덮어쓴다.
- 결과 화면은 `adv_math.php`의 `renderResult`가 기말 세션이면 `window.finalGrading.displaySolution(p.solution)`으로 정답을 표시한다.

## 10. 검증

- `node scripts/check_final.cjs --structure-only`: id 중복·접두어, 세트당 문항 수, level 1–5, `answerType` 접두어 유효성, 중괄호 짝, `$` 없음, `page`가 98–191, `buildProblemHtml()` 렌더 확인
- `node scripts/check_final.cjs --payload | python scripts/check_final.py`: 문항별 독립 계산(아래)과 실제 채점기로 정답·동치 답 정답 처리, 틀린 답 오답 처리
  - 급수의 합: `summation` / `mpmath.nsum`
  - 극한·비·근: `limit`
  - 판정: `Sum(...).is_convergent()`가 되는 것은 자동 확인, 안 되는 것은 해설의 비교 대상 급수를 수치로 확인. 절대/조건은 절댓값 급수도 같이 확인
  - 수렴반경·구간: 비의 극한 + 끝점 급수 판정
  - 테일러: `series()` 계수 비교
  - 미분방정식: `checkodesol` + 초기조건 대입, 오일러는 유리수로 정확 재계산
- 래퍼 단위 테스트(node): 판정 정답/오답/"포기", 구간 괄호 다름, `\left[`·`\lbrack` 입력 정규화, ∞ 표기 3종
- 중간 회귀: 기존 `check_lesson_calculus`, `check_inverse_hyperbolic`, `check_polar`, `check_algebra` 실행 결과가 변경 전과 같은지
- 브라우저: 중간·기말 각 1세트를 끝까지 풀어 채점·결과 화면 확인, 라이트/다크, 모바일 폭

## 11. 진행 순서

1. 뼈대: 시험 탭·기말 과목 탭·`adv_final.js` 골격 + 샘플 문제집 1개 → 중간 회귀 확인
2. 답 형식·채점 래퍼·입력 도구 + 단위 테스트
3. 미분방정식 2세트 + 검증 (이미 배운 범위라 먼저)
4. 급수 10세트 + 검증 (세트 단위로 작성→검증 반복)
5. 실전 모의 1세트
6. 브라우저 점검, `?v=` 갱신, README 업로드 목록

## 12. 구현자에게 맡기는 것

- 시험 탭 줄의 정확한 크기·간격 (기존 탭과 같은 계열 안에서)
- 래퍼 정규화의 세부 규칙 (위 테스트 항목을 통과하는 선에서)
- 각 문항의 구체적인 수치와 문장 (교과서 유형 안에서, 숫자만 바꾼 반복 금지)

## 13. 정한 것

사용자 결정: 기말에는 증명 탭을 두지 않는다.

설계자가 정하고 사용자가 이의를 제기하지 않은 것:

- 처음 들어오면 기말고사 → 급수 탭이 열린다.
- 비율: 급수 50 · 미분방정식 10 · 모의 10.
- `수렴` 정답에는 `절대수렴`도 정답 처리한다.
- 기말에서 포기 버튼을 숨긴다.
- 교과서 문제를 그대로 옮기지 않고 같은 유형으로 새로 만든다.
