# 알고리즘 문제 해결 및 코드 작성 규칙 (C++)

모든 알고리즘 답변은 다음 형식을 엄격히 준수하여 작성해야 함.
같은 문제의 Python 버전(rule.txt)과 상단 설명(제목/문제 설명/시간 복잡도/입출력 예시)은 동일하게 유지한다.

## 1. 문서 상단 구성
- 파일 맨 위에 /* ... */ 블록 주석으로 작성한다 (Python의 '''...''' 독스트링에 대응).
- [문제 제목]: 문제의 핵심 제목.
- 문제 설명: 해결을 위한 핵심 아이디어 설명.
- 시간 복잡도: O(N) 형태의 빅오 표기법 명시.

## 2. 입출력 예시
- [입력 예시] / [출력 예시] 형태로 작성.

## 3. 코드 구현 (C++)
- C++은 문법상 main() 함수가 반드시 필요하므로 Python처럼 완전히 생략할 수는 없다 --
  대신 main() 안의 로직은 별도 함수로 쪼개지 않고 바로 작성한다 (꼭 필요한 알고리즘 자체
  함수, 예: dfs/bfs 재귀 함수는 예외).
- 입출력 효율화: `ios_base::sync_with_stdio(false); cin.tie(NULL);` 를 포함한다.
- 주석: 아래의 필수 주석 섹션만 포함한다.
    1. // 데이터 입력
    2. // 문제 해결 로직
    3. // 결과 출력
- 코드 예시:
    #include <bits/stdc++.h>
    using namespace std;

    int main() {
        ios_base::sync_with_stdio(false);
        cin.tie(NULL);

        // 데이터 입력
        int n;
        cin >> n;

        // 문제 해결 로직
        int result = ...;

        // 결과 출력
        cout << result << "\n";

        return 0;
    }
